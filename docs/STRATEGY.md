# 策略设计说明 — M3GainersTrend

## 0. 为什么不做回测

交易标的是 **币安合约涨幅榜**，构成每分钟都在变化。任何历史回测都只能使用
「今天已知的合约清单」，这在统计上等价于**幸存者偏差 + 前视偏差**的双重污染：
今天能进榜单的币，在历史某时刻可能尚未上线或根本没有流动性。

因此本项目的评估闭环是：**dry-run → 观察统计 → 调参 → 再 dry-run**。
所有参数都以「dry-run 中的真实成交/费率/滑点」为准。

## 1. 收益来源的拆解

对于涨幅榜合约，一个多头头寸的净收益为：

```
净收益 ≈ 价格变动 × 杠杆  − 资金费率支出 × 持仓时长  − 双边手续费  − 滑点
```

热门合约的年化资金费率常落在 **+50% ~ +200%**，即 8 小时结算一次要付出 0.1%~0.4%。
若持有 3 天，仅费率成本就可能吃掉 1%~4% 的价格涨幅 —— 这正是「追涨必亏」的机理。

因此策略的每一层都围绕**费率效率**设计：

1. **只在费率可接受时开多**（年化 ≤ +45%）；费率越极端，评分越低。
2. **优先选择负费率的多头**：价格强势上涨 + 年化费率为负 = **持仓还能收钱**，
   这是本策略追求的「正 Carry 趋势」状态（负费率多头、正费率空头）。
3. **费率反转立刻退出**：持多期间年化 > +90% 说明多头过度拥挤，主动离场。

## 2. 三周期共振

| 周期 | 作用 | 输出 |
|---|---|---|
| 4h | 主趋势方向 | `trend_dir` = +1 / 0 / -1 |
| 1h | 趋势相位 + 强度 | `phase` = +1 / 0 / -1；ADX；距 EMA21 延伸度 |
| 5m | 入场触发 | 突破 / 回踩 / MACD 柱反转 |

**只做「4h 与 1h 同向」**的行情——这是「在主趋势里持续参与」的落地方式。

## 3. 入场条件（做多）

```
① 4h trend_dir ≥ +0.5  且  1h phase ≥ +0.5  且  1h ADX ≥ 15
② 在候选池中(涨幅榜打分) 且 24h 成交额 ≥ 8M USDT 且 盘口价差 ≤ 25bps
③ m3_score ≥ +12
④ 年化费率 ≤ +45%（历史序列 + 实时 premiumIndex 双重校验）
⑤ 5m: EMA21 > EMA50 且 close > EMA50 且 MACD 柱 > 0
⑥ 5m RSI ∈ (45, 78)，1h RSI < 80，距 1h EMA21 延伸 < 12%
⑦ OI 1h 变化 > -8%（资金没有大幅撤退）
⑧ 触发: 20 根新高突破 / 回踩 EMA21 反弹 / MACD 柱由负转正
⑨ 恐贪指数 > 85 时禁止开新多
```

做空条件为镜像，另有「恐贪 < 15 禁止开新空」。

## 4. 风控与仓位

| 项 | 取值 | 说明 |
|---|---|---|
| 杠杆 | 基准 4x，上限 5x | ATR>6% 降至 2.5x；ADX>35 加 0.5x |
| 单笔风险预算 | 0.6% 权益 | `stake = 预算 /(价格止损距离 × 杠杆)` |
| 单笔仓位上限 | 权益的 30% | 下限 3% |
| 并发持仓 | 6 笔 | `max_open_trades` |
| 初始止损 | 2.6 × ATR(5m)，钳制 2%~12% | 价格口径 |
| 硬止损 | 权益 -8.5% | 立即市价 |

> ⚠️ freqtrade 合约模式下 `custom_stoploss` 的返回值是**风险比例**（相对权益，含杠杆），
> 实际价格距离 = |返回值| / 杠杆。本策略统一用 `stoploss_from_absolute()` 做换算，
> 避免不同杠杆下止损位置漂移。

## 5. 出场体系（持续收割）

| 触发 | 动作 |
|---|---|
| 4h 或 1h 趋势反转 | `trend_break`（趋势破坏即离场） |
| 浮盈 > 2.5% | 启动 ATR 跟踪止盈（2.2 × ATR） |
| 浮盈 > 10% / 30% | 分批减仓 35% / 35%（`adjust_trade_position`） |
| 浮盈 > 25% / 60% | 跟踪距离收紧至 6% / 5% |
| 费率年化 > +90%(多) | `funding_exit_long` 主动离场 |
| RSI 极端 + MACD 反向且浮盈 > 3% | `momentum_fade_*` 收割 |
| 持有 > 72h 且 |收益| < 0.4% | `stale_position` 释放资金 |
| 持有 > 240h | `max_hold_time` |

## 6. 迭代方向（待 dry-run 数据验证）

1. **费率收益归因**：统计每笔交易的 `funding_fees` 占总盈亏比例，据此调整费率阈值。
2. **负费率多头的胜率/盈亏比**：验证「正 Carry 趋势」假设是否成立。
3. **OI 背离因子**：价格新高但 OI 不创新高 → 可能是空头回补，应减仓。
4. **榜单名次的时间衰减**：刚进榜（rank 1-10）与长期霸榜的入场期望差异。
5. **多空配比**：在比特币主导的行情中，是否该给空头更严格的门槛。
6. **打分权重再平衡**：用 dry-run 交易结果对 `DEFAULT_WEIGHTS` 做敏感性分析。
